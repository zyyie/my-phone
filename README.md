# HONOR 400 Pro - Official Website

A **modern, responsive landing page** for the **HONOR 400 Pro** smartphone, built using **HTML**, **CSS**,and **Bootstrap**.  
This website showcases the HONOR 400 Pro’s premium design, camera features, detailed specifications, and interactive user experience.

---

## 🌟 Key Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile devices  
- **Interactive Color Selector** — Switch between **Lunar Grey** and **Midnight Black** phone variants  
- **Smooth Scroll Navigation** — Sticky navbar with animated section transitions  
- **Modern Animations** — Hover effects, fade-ins, and smooth UI transitions  
- **Dynamic Sections** — Hero, Overview, Specs, Tips, Gallery, and Contact  
- **Lightweight Performance** — Uses CDN-based Bootstrap and icons for fast loading

## 🚀 Setup & Installation

1. **Download or clone** the repository:
   ```bash
   git clone https://github.com/<your-username>/honor-400-pro-website.git
   ```

2. **Place all image files** in the same directory as `index.html`.

3. **Open** the `index.html` file in your preferred web browser.

4. *(Optional)* Run a local development server for smoother testing:
   ```bash
   python -m http.server 8000
   ```
   Then visit → `http://localhost:8000`

## 🎨 Customization

### To Change Button or Accent Colors
Edit the CSS inside the `<style>` tag:
```css
.btn-primary {
  background-color: #000; /* Customize button color */
}
```

### To Add New Sections
Follow this structure:
```html
<section id="new-section" class="py-5">
  <div class="container">
    <!-- Your content here -->
  </div>
</section>
```
